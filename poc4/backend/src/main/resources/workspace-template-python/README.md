# Manao Python console project

This project was created by the Manao workspace with a fixed Python 3.13 + uv template.

Run the editor's Run action to execute `main.py`; edit `main.py` to change the program.

## Dependencies

Dependencies are declared in `pyproject.toml` and pinned in `uv.lock` by uv. Do not edit
`uv.lock` by hand; add or remove packages through the workspace dependency flow so both
files stay consistent.
