## 尚未修复的浏览器问题

`ModelSettings.tsx`、`StudioConversationPanel.tsx` 和 `ReviewChanges.tsx` 直接调用 `crypto.randomUUID()`，但已接受的产品入口是普通 HTTP。现有 AgentTask / Python dependency 模块已有基于 `crypto.getRandomValues` 的 UUID 生成器，可作为后续最小修复的参照。本轮按合并原版部署与验证，未修改业务代码。

该问题阻断常规浏览器发起新会话、新任务和添加模型；API 链路通过不能替代浏览器产品验收。应先修复 HTTP UUID 兼容，再重发 frontend，并重跑新建会话、添加模型、发送任务及审阅应用的真实浏览器链路。
